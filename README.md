# Plumb

다림줄. 에이전트가 무엇을 지었든, 개발자가 정한 기준선에 대고 잰다.

코딩을 로우 레벨로 두고 개발자는 그 위 계층에서 일하게 하는 로컬 개발 도구다. 개발자는 계약·규칙·요구사항을 결정하고 승인하며 View를 읽는다. 코드는 에이전트가 쓰고, 도구는 그 코드가 승인된 것을 지키는지 검증한다. 기획안은 [Notion](https://app.notion.com/p/3ec07f0265f481188c64e916edd145de)에 있다.

- 개발 순서: [docs/ROADMAP.md](docs/ROADMAP.md)
- 운영 규칙 (이슈 · PR · 서브 에이전트): [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md)

레포 구성(예정): `packages/core` · `packages/adapter-nextjs` · `apps/ui` · `examples/testbed`
